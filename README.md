# AI-Based Rockfall Prediction and Alert System for Open-Pit Mines

## 📌 Project Overview

The AI-Based Rockfall Prediction and Alert System is a safety-focused system designed to predict potential rockfalls in open-pit mines. It uses Artificial Intelligence, sensor data, and real-time monitoring to identify dangerous conditions and provide early warnings.

## 🎯 Objective

The main objective of this project is to improve worker safety by detecting rockfall risks early and sending alerts before a dangerous event occurs.

## ⚙️ How It Works

1. Sensors collect real-time mining environment data.
2. Data such as ground vibration, slope movement, rainfall, and cracks is monitored.
3. The collected data is processed and analyzed.
4. An AI/ML model predicts the level of rockfall risk.
5. The system displays the risk level on a dashboard.
6. Alerts are generated when the risk becomes high.

## 🚨 Risk Levels

- 🟢 **Low Risk** – Normal conditions.
- 🟡 **Medium Risk** – Warning conditions; monitoring is required.
- 🔴 **High Risk** – Dangerous conditions; immediate alert is generated.
